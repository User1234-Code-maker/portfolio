# Сайт-визитка Богдана Корзуна

Личное портфолио: Fullstack-разработчик и музыкант. Многостраничный сайт на **Vue 3 + TypeScript + Vite**, чистый CSS, без UI-библиотек.

## Что внутри

Многостраничный сайт (Vue Router, ленивая загрузка страниц):

| Адрес              | Что там                                                                                                   |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| `/`                | Hero (утверждённый макет) и короткие блоки: проекты, музыка, обо мне, контакты                            |
| `/projects`        | Галерея с фильтром по категориям (Web, ERP, Боты) и анимированным переключением                           |
| `/projects/<slug>` | Страница проекта: описание, стек, схема архитектуры, скриншоты, следующий проект                          |
| `/music`           | Реальные релизы: свой плеер (играет, пауза, перемотка), мини-плеер внизу, ссылки на площадки, дискография |
| `/about`           | Интро с персонажем, разработка и музыка, стек, навыки, опыт, интерактивный таймлайн                       |
| `/contact`         | Крупный CTA, копирование почты с подтверждением, шесть каналов связи                                      |

Что сделано по дизайну и анимации:

- **Заставка** («цифровой рисунок»): сетка, город и шапочка рисуются линиями, затем проявляется логотип и шторка уходит вверх. Показывается один раз на устройство (флаг `boot-v1` в localStorage), заканчивается сразу, как готова главная картинка (минимум 1,5 с, максимум 2,6 с). Пропускается кликом или любой клавишей. При `prefers-reduced-motion` её нет. Показать снова: открыть `/?intro`. Разметка и стили лежат прямо в `index.html`, логика выхода в `src/boot.ts`.
- **Единый мир**: компонент `WorldBackdrop` (сетка, световые пятна, облака, силуэт города) стоит на всех страницах. Музыка получает свой оттенок (`tone="music"`).
- **Переходы между страницами**: светлая шторка с сеткой плюс плавная смена страницы. Скролл наверх происходит, когда новая страница уже встала.
- **Появление при прокрутке**: директива `v-reveal` (opacity и translate), каскад через `--i`, 3D-наклон `v-tilt`, лёгкий параллакс облаков через одну переменную `--sy`.
- **Фирменный знак**: синяя шапочка с ушками (`src/assets/brand/cap.svg`) в шапке, подвале, заставке и favicon (`public/favicon*.png|svg|ico`, `apple-touch-icon.png`).
- **Пасхалки**: котик на внутренних страницах сидит в разных местах, выглядывает с края, подпрыгивает рядом с курсором и мяукает по клику. Котик в Hero подпрыгивает от курсора и клика.
- Музыка и проекты настоящие. Два проекта под NDA (ERP и Telegram-боты) показаны без ссылок и скриншотов, с пометкой NDA. Резюме (RU/EN) скачивается на странице «Обо мне», файлы лежат в `public/cv/`.
- Картинки в WebP с размерами, ниже первого экрана `loading="lazy"`, скелетон при загрузке, анимации только на `transform` и `opacity`.
- Переключатель RU / EN с «ползунком», выбор запоминается. На телефоне меню в бургере.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install     # поставить зависимости
npm run dev     # запустить сайт локально (адрес покажет в терминале)
```

Остальные команды:

| Команда            | Что делает                                              |
| ------------------ | ------------------------------------------------------- |
| `npm run build`    | проверяет типы и собирает сайт в папку `dist`           |
| `npm run preview`  | показывает собранный сайт локально                      |
| `npm run lint`     | ESLint: ищет ошибки в коде                              |
| `npm run format`   | Prettier: приводит код к единому стилю                  |
| `npm test`         | юнит-тесты (Vitest)                                     |
| `npm run test:e2e` | тесты в браузере: Playwright + проверка доступности axe |

Для e2e один раз поставь браузер: `npx playwright install chromium`.

## Как поменять тексты, проекты и ссылки

Данные разложены по файлам в [`src/data/`](src/data):

- [`site.ts`](src/data/site.ts): **контакты** (почта, GitHub, LinkedIn, Telegram, WhatsApp, SoundCloud) и общий объект `site`.
- [`projects.ts`](src/data/projects.ts): проекты. Скопируй блок, поменяй `slug`, `category` (`web`, `erp`, `bots`, `ai`, `lab`), тексты, стек и схему `arch`. Проект под NDA: `nda: true`, без `repo`/`demo`. Скриншоты: список `shots` (WebP 1200×750 в `src/assets/img`).
- [`music.ts`](src/data/music.ts): релизы (название, тип, дата, жанры, треки, ссылки `links`) и площадки `platforms`. У трека поле `src` указывает на mp3 в `public/audio/` (например `audio/album-1234/02-halat.mp3`). Новый трек: сожми mp3 до 128 кбит/с (`ffmpeg -i in.wav -b:a 128k out.mp3`), положи в `public/audio/<релиз>/` и добавь `src`. Новая обложка: положи `cover-*.webp` и `cover-*-sm.webp` в `src/assets/img` и укажи `cover`/`coverSm` у релиза; без них рисуется запасная обложка.
- [`about.ts`](src/data/about.ts): навыки, опыт, этапы таймлайна.
- [`texts.ts`](src/data/texts.ts): тексты интерфейса, отдельно `ru` и `en`. Ключи в обоих языках должны совпадать (проверяет тест).

## Структура

```text
index.html       разметка заставки и её стили
src/
  assets/        картинки, шрифты, brand/cap.svg
  components/    Hero, шапка, карточки, плеер, фон «мира», котик
  composables/   язык, параллакс, плеер (usePlayer), котик в Hero
  data/          тексты, проекты, музыка, о себе
  directives/    v-reveal, v-tilt
  styles/        main.css (Hero и база), pages.css (страницы)
  views/         страницы для роутера
  router.ts      маршруты
  boot.ts        когда убирать заставку
tests/
  unit/          Vitest
  e2e/           Playwright + axe (все страницы, 3 размера экрана)
.github/workflows/
  ci.yml         проверки на ветках и pull request
  deploy.yml     проверки + публикация на GitHub Pages
```

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и отправь туда код (ветка `main`).
2. В репозитории открой **Settings → Pages** и в поле **Source** выбери **GitHub Actions**.
3. Любой пуш в `main` запускает `deploy.yml`: прогоняет проверки, собирает сайт и публикует его.

После сборки `dist/index.html` копируется в `dist/404.html` (скрипт `postbuild`): так прямые ссылки вроде `/projects` открываются и на GitHub Pages.

Адрес в Vite (`base`) подставляется сам: в workflow он равен `/<имя-репозитория>/`. Локально `base` равен `/`. Если сайт будет на своём домене или в репозитории `<логин>.github.io`, поменяй `VITE_BASE` в `deploy.yml` на `/`.

## Заметки

- Картинка для превью в соцсетях лежит в `public/og.jpg`. Для ссылок в мессенджерах нужен полный адрес в теге `og:image`, поэтому после публикации замени его на `https://<адрес-сайта>/og.jpg` в `index.html`.
- Иллюстрации (персонаж, город, кот) сделаны автором. Исходники были маленькими, поэтому персонаж и город увеличены нейросетью Real-ESRGAN (модель для аниме) и подогнаны по цвету к оригиналу. Если сгенерируешь версию побольше, просто замени `src/assets/img/character.webp` и `city.webp` без правок вёрстки.

## Фон, язык и скорость

- **Фон** (`WorldBackdrop`): статичный, облака и город внизу, без тяжёлых эффектов. Игровой слой, след за курсором и демо-плеер убраны ради плавности.
- **Плеер**: один общий `<audio>` в `usePlayer`, мини-плеер `NowPlaying` внизу не прерывается при переходах между страницами. Файлы лежат в `public/audio` (около 36 МБ).
- **Котик** (`PixelCat`): можно перетащить мышкой, пальцем или стрелками (пока несёшь, он кричит «ааа»), сам медленно гуляет, засыпает через 30 секунд и иногда реагирует на клики по странице.
- **Смена языка** (`useLang`): мгновенная, с лёгким затуханием; без анимации при `prefers-reduced-motion`.
- **Скорость**: картинки Hero пережаты в WebP q82 (около 1,3 МБ вместо 2 МБ, вид не изменился), на телефоне подставляется облегчённый город, остальные картинки грузятся лениво, mp3 не грузятся, пока не нажмёшь на трек (`preload=none`).
- Тексты в формате `{ ru, en }` выводятся через `tx()`.
